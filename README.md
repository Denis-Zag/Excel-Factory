# Excel Factory

Приложение создаёт демонстрационный отчёт в существующей Google Таблице. Пользователь задаёт период и название отдела, после чего программа добавляет новый лист, записывает случайные показатели и автоматически оформляет результат.

## Возможности

- подключение к приватной Google Таблице через сервисный аккаунт;
- чтение и запись диапазонов;
- обновление ячейки, добавление и удаление строк;
- создание и удаление листов;
- генерация отчёта через интерфейс `tkinter`;
- автоматическое форматирование заголовков, таблицы, итогов и числовых значений;
- отдельная проверка живого подключения к Google Sheets API.

## Стек

- Python 3.12;
- Google Sheets API v4;
- `google-api-python-client`;
- `google-auth`;
- `python-dotenv`;
- `tkinter` из стандартной библиотеки Python.

## Подготовка Google Таблицы

1. В Google Cloud должен быть включён Google Sheets API.
2. Создайте пустую Google Таблицу вручную.
3. Откройте доступ к таблице для email сервисного аккаунта с ролью «Редактор».
4. Скопируйте ID таблицы из адреса между `/d/` и `/edit`.

## Настройка

Создайте виртуальное окружение и установите зависимости:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Заполните локальный файл `.env`:

```dotenv
GOOGLE_CREDENTIALS_FILE=имя-файла-сервисного-аккаунта.json
SPREADSHEET_ID=идентификатор-таблицы
```

JSON-ключ и `.env` содержат закрытые данные и исключены из Git.

## Проверка подключения

```powershell
python preflight.py
```

Успешная проверка подтверждает авторизацию, доступ к таблице, получение списка листов и чтение первой ячейки.

## Запуск

```powershell
python report_generator.py
```

В окне укажите даты в формате `ДД.ММ.ГГГГ`, название отдела или проекта и нажмите «Сгенерировать отчёт». В Google Таблице появится новый оформленный лист.

## Структура

- `google_sheets.py` — переиспользуемый ООП-клиент Google Sheets;
- `report_generator.py` — интерфейс и формирование отчёта;
- `preflight.py` — живая проверка подключения;
- `.env.example` — пример локальных настроек;
- `requirements.txt` — зависимости проекта.
